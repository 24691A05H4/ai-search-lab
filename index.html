⚖️ Mathematical Formulation

8-Puzzle State Space: $9!/2 = 181,440$ reachable states. Branching factor $b \approx 2.67$.

A* Heuristic: $f(n) = g(n) + h(n)$, where $h(n)$ is Manhattan Distance ($\sum |x_i - x_g| + |y_i - y_g|$). Admissible & consistent.

Tic-Tac-Toe Minimax: Zero-sum 2-player adversarial search. Game tree size $9! = 362,880$. Value propagation: $\max_{a \in A} \min_{b \in B} \text{Utility}(s)$.
